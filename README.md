# IncidentHub

Programa desarrollado en Java para gestionar incidentes técnicos.

## Funcionalidades

- Crear incidentes.
- Calcular prioridades automáticamente.
- Validar la cantidad de usuarios afectados.

## Tecnologías

- Java 21
- IntelliJ IDEA

## Cómo ejecutar el proyecto

- Tener instalado Java 21
- Abrir el proyecto en IntelliJ IDEA.
- Abrir src/Main.java.
- Ejecutar el método main() mediante el botón verde de IntelliJ.
