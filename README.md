# IncidentHub

Sistema de gestión de incidentes informáticos en Java.

## Tecnologías
- Java 21
- IntelliJ IDEA
- Git y GitHub

## Funcionalidades
- Clasificación de incidentes según usuarios afectados.
- Prioridades: CRITICA, ALTA y BAJA.

## Próximas mejoras
- API REST con Spring Boot
- PostgreSQL
- Docker
- Seguridad informática
